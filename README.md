# Murilo Prestes

I work with infrastructure. Linux, networks, VoIP, monitoring and automation.

Most things I put here started with a real problem I had to solve: a server migration, a SIP route behaving badly, a backup that needed checking, a network path that made no sense, or a repetitive task that should have been a script already.

I don't like knowing only the command that fixes something. I want to understand what broke, why it broke and how I can prove it.

## What I work with

- Linux servers — Debian and CentOS
- VoIP — Asterisk, FreePBX, SIP, PJSIP and WebRTC
- Networks — routing, switching, VPNs and troubleshooting
- Packet analysis — tcpdump, sngrep and Wireshark
- Monitoring — Zabbix and Grafana
- Automation — Bash, Ansible and some Python
- Infrastructure — migrations, backups, firewalls, services and troubleshooting
- Cloud — AWS, Azure and DigitalOcean

## Projects

### [infra-scripts](https://github.com/n0nsi/infra-scripts)
Small scripts for backup, network checks, monitoring and VoIP. Most of them are here because I needed the same check more than once and got tired of doing it by hand.

### [testdivoip](https://github.com/n0nsi/testdivoip)
A Bash project for checking network paths used by VoIP environments. It brings ping, MTR, traceroute, ASN information and route analysis into one workflow.

### [infrawifi](https://github.com/n0nsi/infrawifi)
One of my own infrastructure and Wi-Fi projects. It is also where I test how to turn technical work into something people can actually understand outside the terminal.
